# PAC 2 Visualització de dades

Tres visualitzacions estàtiques (HTML + D3 v7) amb les dades incrustades a cada pàgina.

- `index.html` · pàgina d’inici
- `dot-density.html` · conreus llenyosos de Catalunya, 2024
- `small-multiples.html` · fertilitzant per hectàrea, 1961–2023
- `beeswarm.html` · rendiment de cereal, 2016
- `data/` · dades netes en CSV

## Publicar a GitHub Pages
1. Crea un repositori públic i puja tot el contingut d'aquesta carpeta a l'arrel.
2. A *Settings → Pages*, tria *Deploy from a branch*, la branca `main` i la carpeta `/ (root)`.
3. En uns minuts, les pàgines estaran a `https://<usuari>.github.io/<repositori>/`.
